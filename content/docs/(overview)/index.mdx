## 页面布局验证

当前页面可以直接检查以下官方布局能力：

- 搜索框下方显示根目录切换下拉框。
- 侧边栏左下角显示 GitHub 仓库图标和主题切换。
- 页面标题下方显示 **Copy Markdown** 和 **Open** 操作。
- 页面右侧显示自动生成的目录。
- 页面底部显示最后更新时间以及上一篇、下一篇导航。

下面的 `npm` 代码块会自动生成 npm、pnpm、yarn 和 bun 标签，并记住用户选择。

