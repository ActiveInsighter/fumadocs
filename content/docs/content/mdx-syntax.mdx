## Frontmatter

页面顶部使用 YAML Frontmatter 定义标题、描述、图标和布局选项。

```mdx
---
title: 页面标题
description: 页面描述
icon: FileText
full: false
---
```

| 字段 | 作用 |
| --- | --- |
| `title` | 页面标题和侧边栏名称 |
| `description` | 页面简介和 SEO 描述 |
| `icon` | 页面树图标名称，由 Lucide 图标插件解析 |
| `full` | 是否让正文占满可用空间 |

## 标题、锚点与目录

```md
## 普通标题

## 自定义锚点 [#installation]

## 不显示在目录中 [!toc]

## 只加入目录 [toc]
```

自定义锚点适合创建稳定链接：

```md
[跳转到安装章节](#installation)
```

<Callout type="warn" title="标题层级">
  Frontmatter 的 `title` 已经作为一级标题渲染，正文通常从 `##` 开始，避免页面中出现两个一级标题。
</Callout>

## 文本格式

```md
**粗体**

*斜体*

~~删除线~~

`行内代码`

> 引用内容
```

实际效果：**粗体**、*斜体*、~~删除线~~、`行内代码`。

## 链接

```md
[站内页面](/docs/components)

[相对页面](../components/tabs-accordions)

[外部网站](https://example.com)

<https://example.com>
```

项目已经通过 `createRelativeLink()` 处理 MDX 相对链接，拆分或调整文档目录时更容易维护。

## 图片

```md
![图片替代文本](/fumadocs-capabilities.svg)
```

普通 Markdown 图片已经统一映射到 `ImageZoom`，点击后可以查看大图。

也可以使用 JSX 指定更多属性：

```mdx
<img
  src="/fumadocs-capabilities.svg"
  alt="Fumadocs 能力图"
  width="1200"
  height="630"
/>
```

## 分隔线与换行

```md
上一段

---

下一段
```

Markdown 中空一行表示新段落。确实需要强制换行时，可以在行尾添加两个空格，但通常更推荐使用自然段落。

## 注释

MDX 页面中可以使用 JSX 注释：

```mdx
{/* 这段内容不会显示到页面中 */}
```

普通 HTML 注释可能被处理器保留或移除，因此 MDX 中优先使用 JSX 注释。

## JSX 表达式

MDX 可以直接使用 JavaScript 表达式和组件：

```mdx
<p>计算结果：{1 + 2}</p>

<Callout type="success">
  这里使用的是 React 组件。
</Callout>
```

复杂逻辑更适合封装成 React 组件，再在 `components/mdx.tsx` 中全局注册。

## 特殊字符与转义

Markdown 特殊字符前添加反斜杠：

```md
\*不会变成斜体\*

\# 不会变成标题

\{不会作为 MDX 表达式执行\}
```

在 MDX 正文中直接书写 `<`、`>`、`{`、`}` 时需要格外注意，因为它们可能被解析为 JSX。可以使用反斜杠、行内代码或 HTML 实体。
