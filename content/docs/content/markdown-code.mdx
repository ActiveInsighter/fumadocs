## GitHub Flavored Markdown

| --- | --- | --- |

## 标题、行号与高亮

```tsx title="components/example.tsx" lineNumbers
export function Example() {
  const docs = 'Fumadocs'; // [!code highlight]
  const mode = 'default';

  return <p>{docs}: {mode}</p>;
}
```

## 包管理器自动切换

`npm` 代码块会由 Fumadocs 自动转换为多个包管理器标签。

```npm
npm install fumadocs-core fumadocs-ui
```
