## 显式 Steps 组件

<Steps>
  <Step>

### 创建文档目录

在 `content/docs` 中创建页面和文件夹。

  </Step>
  <Step>

### 编写 MDX

使用 Markdown 语法，并按需插入已经注册的 React 组件。

  </Step>
  <Step>

### 构建验证

运行 `pnpm check` 同时完成类型检查与生产构建。

  </Step>
</Steps>

## 标题自动转换为步骤

下面的标题带有 `[step]` 标记，由 `remarkSteps` 自动转换，无需手写组件。

### 准备配置 [step]

确认 `source.config.ts` 已启用所需插件。

### 添加页面 [step]

创建 `.mdx` 文件并写入 Frontmatter。

### 检查结果 [step]

启动开发服务器，在侧边栏中打开新页面。

## files 代码块

下面的普通代码块由 `remarkMdxFiles` 自动转换为可交互的文件树。

```files
fumadocs-site
├── app
│   ├── docs
│   │   └── [[...slug]]
│   │       └── page.tsx
│   └── layout.tsx
├── components
│   └── mdx.tsx
├── content
│   └── docs
│       └── index.mdx
├── source.config.ts
└── package.json
```
