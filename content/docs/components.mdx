## 标准 Markdown

支持 **粗体**、_斜体_、~~删除线~~、`行内代码`、[内部链接](/docs)与[外部链接](https://vite.dev)。

> 引用块适合放置定义、结论或来自其他资料的内容。

- 无序列表
  - 支持嵌套项目
  - 支持 **Markdown** 格式
- 适合整理并列知识点

1. 第一步：创建 MDX 文件
2. 第二步：加入 `meta.json`
3. 第三步：提交并自动部署

| 能力 | 写法 | 当前状态 |
| --- | --- | --- |
| GFM 表格 | Markdown 表格 | 可用 |
| 自动链接 | 直接书写 URL | 可用 |
| 任务列表 | `- [x]` | 可用 |
| MDX 组件 | JSX 标签 | 可用 |

- [x] React Router 静态构建
- [x] Cloudflare Pages 部署
- [x] Fumadocs 静态搜索
- [x] Copy Markdown 与 Open 菜单

## Accordions 折叠面板

<Accordions type="multiple">
  <Accordion title="文档写在哪里？">
    页面放在 `content/docs`，目录顺序由同级 `meta.json` 控制。
  </Accordion>
  <Accordion title="搜索是否需要服务器？">
    当前项目把 `/api/search` 预渲染为静态索引，因此 Pages 不需要额外函数。
  </Accordion>
  <Accordion title="Copy Markdown 如何工作？">
    每篇文档都会生成独立的 `content.md` 静态资源，官方按钮按需获取并复制内容。
  </Accordion>
</Accordions>

## 页面级实用功能

每篇文档顶部现在包含：

- **Copy Markdown**：复制处理后的 Markdown 文本；
- **Open**：打开 GitHub 源文件、Markdown 版本或 AI 工具；
- **文档切换器**：在快速开始、组件示例与长文档之间切换；
- **Last updated on**：根据该文件最后一次 Git 提交显示日期；
- **GitHub 图标**：位于左侧栏底部，可直接进入仓库。
