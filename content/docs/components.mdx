## Accordions 折叠面板

<Accordions type="multiple">
  <Accordion title="文档放在哪里？">
    把 `.mdx` 文件放在 `content/docs` 目录中。
  </Accordion>
  <Accordion title="如何新增侧边栏页面？">
    在 `content/docs/meta.json` 的 `pages` 数组中加入文件名。
  </Accordion>
  <Accordion title="搜索接口在哪里？">
    搜索接口位于 `/api/search`，由 Fumadocs Search Server 提供。
  </Accordion>
</Accordions>

## Steps 步骤

<Steps>
  <Step>
    ### 编写文档

    在 `content/docs` 下创建 MDX 文件。
  </Step>
  <Step>
    ### 本地预览

    运行 `pnpm dev` 并打开浏览器。
  </Step>
  <Step>
    ### 生产构建

    运行 `pnpm build` 生成客户端与 SSR 产物。
  </Step>
</Steps>
