## 架构原则

这个项目将内容能力和视觉表现分开维护：

- **Fumadocs** 负责 MDX 内容源、页面树、侧边栏、目录、搜索和文档路由。
- **Animate UI 风格层** 负责主题变量、玻璃导航、按钮反馈、侧边栏状态和轻量动画。
- **项目代码** 只保留真正需要的组件，不复制 Registry、AI、MCP 或组件分发平台。

## 已实现功能

| 模块 | 当前实现 |
| --- | --- |
| 文档内容 | `content/docs` 下的 MDX 文件 |
| 目录结构 | Fumadocs 页面树和 `meta.json` |
| 搜索 | `/api/search` 本地搜索接口 |
| Markdown 输出 | 单页 Markdown 与 `/llms-full.txt` |
| 主题 | 浅色、深色和系统主题 |
| 动画 | Motion 首页动效与 CSS 微交互 |
| Run ID | GitHub Actions 自动记录当前及最近运行 |
