## 实现原理

`source.config.ts` 开启了 `includeProcessedMarkdown`。构建时，Fumadocs MDX 会保留适合 AI 阅读的处理后 Markdown，运行时通过 `page.data.getText('processed')` 获取。

```ts title="lib/get-llm-text.ts"
export async function getLLMText(page) {
  const processed = await page.data.getText('processed');
  return `# ${page.data.title}\n\n${processed}`;
}
```

## 页面 Markdown 重写

`next.config.mjs` 把 `/docs/:path*.md` 重写到专用 Route Handler，因此原始文档 URL 与 Markdown URL 保持一致的路径结构。
