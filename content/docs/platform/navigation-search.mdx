## 当前目录结构

Fumadocs 根据 `content/docs` 的目录结构生成路由和侧边栏页面树：

```files
content/docs
├── (overview)
│   ├── index.mdx
│   └── meta.json
├── components
│   ├── index.mdx
│   ├── callouts-cards.mdx
│   ├── tabs-accordions.mdx
│   ├── steps-files.mdx
│   ├── data-display.mdx
│   └── meta.json
├── content
│   ├── index.mdx
│   ├── mdx-syntax.mdx
│   ├── markdown-code.mdx
│   ├── math-mermaid.mdx
│   ├── includes.mdx
│   └── meta.json
├── platform
│   ├── index.mdx
│   ├── page-features.mdx
│   ├── navigation-search.mdx
│   ├── feedback.mdx
│   ├── ai-exports.mdx
│   └── meta.json
└── meta.json
```

圆括号目录是路由分组，`(overview)/index.mdx` 的地址仍然是 `/docs`。

## 搜索框下方的根目录切换器

截图中的下拉切换器来自 Fumadocs 的 **Layout Tabs**。只需把文件夹标记为根目录：

```json title="content/docs/components/meta.json"
{
  "title": "组件示例",
  "description": "常用内容组件与交互组件",
  "icon": "Blocks",
  "root": true,
  "pages": [
    "index",
    "callouts-cards",
    "tabs-accordions"
  ]
}
```

当前项目已经把总览、组件示例、内容能力和平台能力设置为四个根目录。打开其中任意页面后，侧边栏只显示当前根目录内容，切换器用于进入其他分类。

也可以在布局中手工指定：

```tsx
<DocsLayout
  tabs={[
    {
      title: '组件示例',
      description: '常用内容组件',
      url: '/docs/components',
    },
    {
      title: '内容能力',
      description: 'Markdown 与 MDX',
      url: '/docs/content',
    },
  ]}
/>
```

通常优先使用 `meta.json`，因为页面树、面包屑和导航可以共享同一份结构信息。

## Lucide 图标

页面树本身不绑定具体图标库。本项目在 `loader()` 中启用了 Lucide 图标插件：

```ts title="lib/source.ts"
import { loader } from 'fumadocs-core/source';
import { lucideIconsPlugin } from 'fumadocs-core/source/lucide-icons';

export const source = loader({
  baseUrl: '/docs',
  source: docs.toFumadocsSource(),
  plugins: [lucideIconsPlugin()],
});
```

之后可以在 Frontmatter 或 `meta.json` 中写图标名称：

```mdx
---
title: 搜索
icon: Search
---
```

## meta.json 排序

`pages` 决定侧边栏、页脚上一篇/下一篇以及部分面包屑的顺序：

```json
{
  "title": "内容能力",
  "defaultOpen": true,
  "pages": [
    "index",
    "mdx-syntax",
    "markdown-code",
    "---高级内容---",
    "math-mermaid",
    "includes"
  ]
}
```

常用写法：

```json
{
  "pages": [
    "index",
    "---[Blocks]组件---",
    "...",
    "!draft",
    "[GitHub](https://github.com/owner/repo)",
    "external:[官方网站](https://example.com)"
  ]
}
```

| 写法 | 作用 |
| --- | --- |
| `...` | 插入尚未列出的剩余页面 |
| `z...a` | 以反向顺序插入剩余页面 |
| `!draft` | 从剩余页面中排除某项 |
| `...folder` | 把子文件夹内容提升到当前层级 |
| `---标题---` | 插入侧边栏分隔标题 |
| `[文字](url)` | 添加站内或站外链接 |
| `external:` | 明确标记外部链接 |

## 文件夹首页

文件夹中存在 `index.mdx` 时，文件夹标题可以直接进入分类首页。也可以使用 `pagesIndex` 指定其他页面：

```json
{
  "pagesIndex": "overview",
  "pages": [
    "overview",
    "installation"
  ]
}
```

## 侧边栏左下角 GitHub 图标

在共享布局配置中提供 `githubUrl`：

```tsx title="lib/layout.shared.tsx"
import type { BaseLayoutProps } from 'fumadocs-ui/layouts/shared';

export function baseOptions(): BaseLayoutProps {
  return {
    nav: {
      title: 'Fumadocs',
    },
    githubUrl: 'https://github.com/ActiveInsighter/fumadocs',
  };
}
```

Docs Layout 会按照官方默认布局把仓库按钮放到侧边栏底部，并与主题切换控件对齐。

## 其他布局链接

```tsx
export function baseOptions(): BaseLayoutProps {
  return {
    links: [
      {
        text: '博客',
        url: '/blog',
        active: 'nested-url',
      },
      {
        type: 'icon',
        label: '项目状态',
        icon: <ActivityIcon />,
        url: '/status',
      },
    ],
  };
}
```

链接还支持菜单和自定义 React 组件。

## GitHub 仓库信息组件

需要同时显示仓库名称和 Star 数时，可以使用：

```tsx
import { GithubInfo } from 'fumadocs-ui/components/github-info';

<GithubInfo
  owner="ActiveInsighter"
  repo="fumadocs"
  token={process.env.GITHUB_TOKEN}
/>
```

公开仓库可以不提供 Token；频繁构建或私有仓库建议配置 Token，避免 GitHub API 限流。

## 默认搜索

项目的搜索 Route Handler 使用 `createFromSource(source)`，会从 Fumadocs 内容源创建搜索接口。顶部搜索框可以检索页面标题、描述和正文。

```ts title="app/api/search/route.ts"
import { createFromSource } from 'fumadocs-core/search/server';
import { source } from '@/lib/source';

export const { GET } = createFromSource(source);
```

## 搜索扩展

文档量增大后，可以迁移到：

- Orama Cloud
- Algolia
- Typesense
- Mixedbread
- 自定义搜索服务

页面 MDX 不需要随搜索后端一起重写，只需替换搜索接口和客户端适配器。

## 标题与搜索结果

搜索结果和页面目录依赖构建时生成的标题数据。给重要章节设置稳定锚点，可以避免修改中文标题后旧链接失效：

```md
## 部署配置 [#deployment]
```
